## 1. Introduction

Input and output devices are very important because they allow users to communicate with computers and computers to interact with the real world.

Input devices send information to the computer, while output devices show the results in the real life. Examples include keyboards, mice, monitors, printers and speakers.

![Imagen introduccion](https://www.ceupe.com/images/easyblog_articles/3948/b2ap3_amp_perifricos.png)

## 2. Main Functions

The main function of peripherals is to send information to the computer or receive information from it as I say later. They connect to the computer through different ports or wireless connections.

- **Input devices:** A keyboard allows us to type text, and a mouse helps us control the cursor.
- **Output devices:** A monitor displays images and text, while a printer produces documents on paper.

Peripherals also work with other computer components. For example, the CPU processes the information entered using a keyboard, and the monitor displays the results. Or de motherboard using it ports to connect to the computer

![Imagen introduccion](https://luckyfalconcomputers.com/wp-content/uploads/2023/11/Input-And-Output-Devices-List-1024x764.jpg)

## Key Specifications

- **Connection:** Devices can use USB cables, HDMI or wireless connections such as Bluetooth.
- **Speed:** It measures how quickly a device transfers information or performs its function.
- **Resolution:** It determines the quality and detail of images displayed or captured.
- **Compatibility:** A peripheral must be compatible with the computer and its operating system.
- **Power consumption:** It indicates how much electricity the device uses.
